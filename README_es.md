`injective-ts` es un monorepo de TypeScript que contiene paquetes que pueden utilizarse para interactuar con Injective desde entornos Node.js o del navegador, y que ofrecen abstracciones simples sobre estructuras de datos básicas, serialización, gestión de claves y generación de solicitudes API, entre otros. Los paquetes se encuentran en la carpeta `packages`, y cada uno de ellos es un módulo `npm` publicado en el registro `npm`.

Obtenga más información en nuestras [documentaciones](https://docs.ts.injective.network/)
