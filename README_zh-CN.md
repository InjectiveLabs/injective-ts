_无障碍地进入无限多样的去中心化金融市场。_

`injective-ts` 是一个 TypeScript Monorepo，其中包含多个包，这些包可用于在 Node.js 或浏览器环境中与 Injective 进行交互，同时还能为核心数据结构、序列化、密钥管理以及 API 请求生成等功能提供简洁的抽象层。这些包位于 `packages` 文件夹中，每个包都是一个发布在 `npm` 注册表上的 `npm` 模块。

欢迎访问我们的[文档页面](https://docs.ts.injective.network/)了解更多信息。
