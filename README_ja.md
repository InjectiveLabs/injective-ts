`injective-ts`はTypeScriptをベースにしたモノレポで、Node.jsやブラウザ環境からInjectiveと連携するためのパッケージが含まれています。また、コアデータ構造、シリアライゼーション、キー管理、APIリクエストの生成などに関するシンプルな抽象化も提供しています。これらのパッケージは`packages`フォルダにあり、各パッケージは`npm`レジストリに公開されている`npm`モジュールです。

詳細は当社の[ドキュメント](https://docs.ts.injective.network/)をご覧ください。
